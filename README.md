# Peg Champ 日本語化パッチ

Peg Champ向けの非公式日本語化パッチです。現行版は **v1.1** です。

**[日本語化パッチ v1.1 をダウンロード](PegChamp_JP_v1_1.zip?raw=true)**

上のリンクから導入用ZIPをダウンロードし、展開して使用してください。

ZIPの展開だけでは適用されません。展開したフォルダー内のインストーラーを実行してください。

## 対応内容

- メニュー、設定、セーブ選択、ステージ名、モード説明
- アップグレード、レリック、帽子名、結果画面など
- 日本語フォントと長い説明文の折り返し
- 本体のバージョン確認、自動バックアップ、復元

v1.1では日本語フォントの文字幅と高さを初版の約72%に縮小し、セーブ選択のはみ出しを修正しました。

## 対応するゲーム本体

ファイル名：`peg_champ_beta.exe`

SHA-256：

```text
89ba8de69c4b3d7ea8c12db253ae220e14e3819cfc667af735a7ce92db5f921b
```

この内容と一致する本体専用です。ゲームのアップデートなどで内容が変わった場合、適用を中止します。

## Steam Deck

1. ゲームを終了し、デスクトップモードに切り替えます。
2. Steamの「ローカルファイルを閲覧」でゲームフォルダーを開きます。
3. ZIP内の `PegChamp_JP_v1` フォルダーを、本体EXEと同じフォルダーへ置きます。
4. `PegChamp_JP_v1` 内でターミナルを開き、次を実行します。

```bash
bash install.sh
```

Steamから通常どおり起動し、ゲーム内の言語を **英語／米国旗** にしてください。
Python 3の標準ライブラリーだけを使用します。

## Windows

同様にフォルダーを置き、`PegChamp_JP_v1/install.bat` を実行してください。
Windows付属のPowerShellを使用します。

## v1.0からの更新

ゲームを終了し、以前のパッチフォルダーに新しい内容を上書きして、インストーラーを再実行します。
アンインストールは不要です。本体の隣の `.jpmod-original` バックアップは残してください。

## 元に戻す

ゲームを終了してから、Steam Deckでは次を実行します。

```bash
bash uninstall.sh
```

Windowsでは `uninstall.bat` を実行してください。セーブファイルは操作しません。

## 確認範囲

Linux版Godot 4.7.2で日本語表示・折り返し・セーブ枠の収まりを確認しています。
Python版の新規適用、v1.0からの更新、再実行、復元、バージョン違いの拒否を検証しています。
Windows版インストーラーの実行と全ステージの通しプレイは未確認です。
